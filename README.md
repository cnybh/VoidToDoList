# VoidToDoList

极简主义工作待办事项清单助手

Minimalist work to-do list assistant

----------------------------------------

![image](https://github.com/cnybh/VoidToDoList/blob/main/logo.jpg?raw=true)

------

![image](https://github.com/cnybh/VoidToDoList/blob/main/view.jpg?raw=true)

------

VoidToDoList 是一个常驻在桌面上的待办清单。它不像普通软件那样占据一个窗口和任务栏位置，而是把自己"贴"在桌面上，安静地待在所有窗口的后面。你工作时它不会挡住任何东西，需要记录点什么的时候，它就在那里。
